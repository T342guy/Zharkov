# Zharkov
*A personal constructed language (conlang) with a harsh, guttural Russian/German-inspired sound*

Zharkov is my private language project — designed to feel raw, throaty, and strong while remaining easy to type and read using only standard English letters + macrons (ā ē ī ō ū) for long vowels.

The name **Zharkov** comes from *zarkh* (“big/strong”) + a Slavic-style *-ov* ending, evoking a powerful, ancient tongue spoken in cold northern lands.

## Core Features

- **Aesthetic**: Harsh & guttural — heavy consonant clusters (kr-, thr-, kh-, pht-, zhr-, shk-), back-throat sounds (kh, gh, growly r), long drawn vowels for menace.
- **Alphabet**: Plain A–Z + macrons (ā ē ī ō ū) for long vowels. No special characters or diacritics beyond the bar.
- **Word order**: SVO (Subject–Verb–Object) — logical and English-like for easy fluency.
- **Pronunciation tips**:
  - **kh** = harsh throat ch (German “Bach”, Scottish “loch”)
  - **gh** = raspy voiced version (throaty gargle)
  - **r** = uvular/trilled/growly (French/German-style back-of-throat r)
  - Long vowels (ā ō ū etc.) = held twice as long, deep & menacing
  - Clusters = smash them together aggressively (e.g., thrāk = “thraaak” with rasp)

## Basic Grammar

- **Articles**  
  da = the (definite)  
  en = a/an (indefinite)

- **Plurals**  
  Add **-ar** (e.g., krāg → krāgar = fires)

- **Tense prefixes** (on verbs)  
  Present: no prefix  
  Past: **za-** (e.g., za-grush = ate)  
  Future: **khra-** (e.g., khra-grush = will eat/drink)

- **Prepositions** (before nouns)  
  in    = in / at  
  to    = to / toward  
  from  = from  
  mit   = with

- **Possession**  
  Owner directly before noun (gak shkva = my house)

## Example Sentences

1. Gak khtōr thrāk.  
   → I see you.

2. Thrāk grush da skūr.  
   → You drink the water.

3. Vorg za-grush en krāg.  
   → We ate a fire.

4. Gak drak to da shkva.  
   → I go to the house.

5. Thrāk mit zarkh khtōr rākh.  
   → You look strong and good. (lit. “You with strength see good”)

6. Da phtik krāg nyet rākh.  
   → The small fire is not good.

7. Vorg khra-grush skūrar mit krāg in shkva.  
   → We will drink waters with fire in the house.  
   (We’ll have drinks by the fire at home.)
